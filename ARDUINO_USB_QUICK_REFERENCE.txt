ARDUINO USB DETECTION SYSTEM - QUICK REFERENCE
==============================================

CRITICAL FIRMWARE REQUIREMENT:
Each Arduino MUST have this line in setup():
    Serial.println("DEVICE_ID:DEVICE_TYPE");

SUPPORTED DEVICE TYPES:
- SERVO_CONTROLLER (pan/tilt/lung servos)
- HAND_CONTROLLER (5-finger hand)
- LIGHTBULB_CONTROLLER (PWM lightbulb)
- GRBL_CNC_CONTROLLER (drawing machine)
- UARM_SWIFT_CONTROLLER (robotic arm)

HOW IT WORKS:
1. Scans all /dev/ttyUSB* and /dev/ttyACM* ports
2. Resets each Arduino with DTR signal
3. Reads DEVICE_ID startup messages
4. Maps devices to ports automatically
5. Sets environment variables
6. Initializes controllers with correct ports

ENVIRONMENT VARIABLES SET:
DETECTED_SERVO_PORT
DETECTED_HAND_PORT
DETECTED_LIGHTBULB_PORT
DETECTED_GRBL_PORT
DETECTED_UARM_PORT

USAGE:
python machine.py              # Normal operation
python machine.py --debug      # See detection process

TESTING:
python debug/arduino_diagnostic_tool.py
env | grep DETECTED

TROUBLESHOOTING:
- Check USB connections
- Verify DEVICE_ID in Arduino firmware
- Ensure user in 'dialout' group: groups
- Test specific port: python debug/arduino_diagnostic_tool.py --port /dev/ttyUSB0

KEY FILES:
- machine.py (main detection function)
- ARDUINO_USB_DETECTION_SYSTEM.md (full documentation)
- debug/arduino_diagnostic_tool.py (testing tool)

ARDUINO FIRMWARE TEMPLATE:
void setup() {
  Serial.begin(9600);
  Serial.println("DEVICE_ID:YOUR_DEVICE_TYPE");
  // ... rest of setup
}

ADDING NEW DEVICE:
1. Flash Arduino with correct DEVICE_ID
2. Connect to any USB port
3. Restart machine.py
4. Device auto-detected - no code changes needed!

SYSTEM BENEFITS:
✅ Zero manual USB port configuration
✅ Plug and play - works with any USB port
✅ Crash-proof and self-healing
✅ Supports unlimited Arduino expansion
✅ No system restart needed for USB changes
