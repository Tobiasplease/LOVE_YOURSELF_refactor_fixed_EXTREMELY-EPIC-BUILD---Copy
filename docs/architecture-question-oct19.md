# Parked: the wider architectural question (Oct 19 2026)

Raised by the artist mid-run, explicitly as an ASIDE — not to be worked on while
the current tests are live. Written down so it is not lost.

The ask: the pipeline was designed in early 2025; the novelty of an LLM
narrating a room is over. What would make the piece lastingly impressive, in
reactivity, personality and narrative embodiment, rather than another round of
prompt repair?

The observation that connects it to the Oct 18 measurements: the machine
produces ~7,000 utterances a day and roughly one drawing a month. A system
required to speak every eight seconds with that little happening will chant —
and every fix so far has only changed WHAT it chants (30 days -> degrees -> the
stamped-log format rebuilt out of angles). That is a ratio problem, not a prompt
problem.

Four structural complaints, in brief:
1. No persistent mind — a paragraph is rebuilt every 8s and thrown away, so
   there is no medium for development to live in.
2. The frame is a committee of ~15 subsystems with no editor deciding what
   matters now; removing one line leaves a vacuum another fills.
3. Everything flattens to English in one paragraph — perception, memory, desire
   all weighted the same.
4. Every moment is equally important: 7,000 same-sized utterances a day, so
   nothing can accumulate.

Leverage, in the order argued:
1. More action, more often — any act with a perceivable consequence. Changes
   what the piece IS; most of what we debug is the symptom of nothing to report.
2. Two speeds — a small cheap model for continuous noticing, the big model
   rarely and at length. (Note: the best output of the Oct 18 run came from the
   slow reflection channel, not the 8-second loop.)
3. One continuous context instead of a rebuilt frame — long context and caching
   are cheap now in a way they were not in early 2025.
4. Fine-tune the voice (the LoRA plan already in the repo) so the persona does
   not have to be argued into being on every call.
5. The diary — still worth doing, but a fix INSIDE the current paradigm.

Next step if resumed: take the piece apart on paper — what it would look like
built now, same room, same arm, same pen. A design argument to disagree with,
not a rewrite plan.
