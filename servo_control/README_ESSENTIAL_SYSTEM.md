## How to Use

1. **Run the system:**
   ```bash
   python run_essential_system.py
   ```

2. **Learn emotions:**
   - Type emotion name (happy, sad, excited, calm, etc.)
   - Click "Start Learning"
   - Move mouse in the black area while expressing that emotion
   - Click "Stop Learning" when done

3. **Express emotions:**
   - Select learned emotion from dropdown
   - Click "Express This Emotion"
   - Watch AI express YOUR movement patterns!

4. **Connect hand (optional):**
   - Click "Connect Hand Controller"
   - Physical hand will move based on AI's emotional state
